# Humanities Superpowers project instructions

For humanities research, scholarly argument, close reading, literature review, citation work, manuscript review, or reviewer response:

1. Inspect `skills/using-humanities-superpowers/SKILL.md`.
2. Select skills by their `description`; do not load every skill without need.
3. Read the full selected `SKILL.md` before acting.
4. Preserve the distinction among verified fact, source-supported interpretation, inference, hypothesis, and unknown.
5. Never invent quotations, page numbers, publication data, DOIs, archival identifiers, or source contents.
6. Obey stop signals. Missing evidence is not permission to fill a gap.
7. When the user asks whether a manuscript is complete or submission-ready, run `verifying-before-submission` and report unresolved failures.
8. `structuring-humanities-argument` may organize researcher-provided material but must not impersonate the researcher's original scholarly judgment.
