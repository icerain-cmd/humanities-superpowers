# Security and research-data safety

This repository contains Markdown instructions and validation scripts; it does not require network access or credentials.

## Reporting

Report security problems privately to `icerain@jj.ac.kr`.

## Research-data warning

Do not place confidential interviews, identifiable participant data, unpublished archival images, copyrighted full texts, credentials, API keys, or private reviewer correspondence in public examples or issue reports.

`verifying-before-submission` includes a privacy check, but maintainers and users remain responsible for data protection and research ethics.
