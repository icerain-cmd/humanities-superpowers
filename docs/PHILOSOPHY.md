# Project philosophy

Humanities Superpowers treats AI-assisted research as a problem of **scholarly judgment under conditions of accelerated text production**.

The project is built around four commitments.

## 1. Judgment is the scarce resource

AI systems can produce more prose than researchers can responsibly verify. The limiting factor is therefore not text generation but judgment: deciding what is researchable, what a source supports, where a concept changes meaning, and when a manuscript is ready.

## 2. Uncertainty must remain visible

A responsible system preserves distinctions among verified evidence, interpretation, inference, hypothesis, and unknown information. It does not convert lack of evidence into stylistic confidence.

## 3. Method should constrain fluency

The repository uses skills, templates, and gates to slow work at high-risk moments. The framework is intentionally capable of returning `FAIL`.

## 4. Human responsibility is irreducible

The agent may compare, organize, test, and flag. The researcher remains responsible for interpretation, verification, ethical judgment, disclosure, and submission.
