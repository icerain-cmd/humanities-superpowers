# Humanities Superpowers v1.0.0

The first public release introduces a structured research workflow for humanities scholars using AI agents.

## Included

- 13 core research skills at Level 2;
- 1 Level 3 router (`using-humanities-superpowers`);
- research state machine and rollback protocol;
- explicit skill contracts and epistemic states;
- citation, terminology, peer-review, and submission gates;
- deterministic repository and integrated workflow tests;
- examples that preserve unresolved failures instead of hiding them;
- installation guidance for Claude Code, Codex, and Cursor;
- English and Korean documentation;
- a GitHub Pages documentation site.

## Position

Humanities Superpowers is not an AI paper writer. It supports scholarly judgment without replacing researcher responsibility.

## Known limitations

This release does not demonstrate that the framework improves publication outcomes, guarantees factual accuracy, or behaves identically across agent harnesses. Real-world user evaluation remains future work.
