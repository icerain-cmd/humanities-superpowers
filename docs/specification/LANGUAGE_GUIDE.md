# Language and Terminology Guide

## 1. Goal

Skills must be precise without sounding bureaucratic. Normative language is used for obligations; interpretive language remains appropriately qualified.

## 2. Requirement terms

- **MUST / MUST NOT:** required for conformance or integrity.
- **SHOULD / SHOULD NOT:** strong recommendation; deviations need a reason.
- **MAY:** permitted option.
- **RESEARCHER DECISION REQUIRED:** the agent must pause or clearly request approval.

Do not use `must` for a debatable interpretation merely to make it sound strong.

## 3. Epistemic terms

Use these consistently:

- **verified:** checked against identified evidence;
- **supported:** evidence provides a defensible basis but may not settle the issue;
- **inference:** conclusion reasoned from stated premises;
- **hypothesis:** provisional explanation;
- **unverified:** not yet checked;
- **unknown:** currently unavailable;
- **disputed:** credible disagreement remains.

Avoid vague substitutes such as “obviously,” “clearly,” “undeniably,” or “it is well known” unless the statement is genuinely uncontested and does not need sourcing.

## 4. Completion language

Forbidden without a gate report:

- complete;
- fully verified;
- submission-ready;
- citation-safe;
- error-free;
- comprehensive.

Preferred:

- “The question gate passes under the stated scope.”
- “Three citation records remain unverified.”
- “The argument is conditionally ready for manuscript review.”

## 5. Agent voice

Skills SHOULD use direct procedural language. They SHOULD NOT imitate a journal referee’s authority when no independent review occurred.

Use:

> The current evidence does not establish the causal claim.

Avoid:

> This argument is definitively wrong.

## 6. Researcher voice

When restructuring prose, preserve the researcher’s conceptual commitments and mark substantive additions. Do not homogenize all humanities writing into generic social-science prose.

## 7. Terminology discipline

A skill MUST distinguish:

- term;
- concept;
- category;
- metaphor;
- method;
- object of analysis.

These labels are not interchangeable.

## 8. Citation language

Use “the source states” only when the relevant passage has been checked. Otherwise use:

- “The supplied note attributes this view to…”
- “The bibliography lists…”
- “This claim remains to be verified against the source.”

## 9. Inclusive and international language

Examples SHOULD avoid assuming one national academic system. Platform instructions may be concrete, but scholarly procedures SHOULD remain adaptable across languages, disciplines, and citation styles.

## 10. Good and bad formulations

Bad:

> Find citations that prove my theory.

Good:

> Identify sources that support, complicate, or challenge the provisional claim, and preserve disagreement.

Bad:

> Make this groundbreaking.

Good:

> Test whether the claimed contribution is distinct from the nearest established concepts.
