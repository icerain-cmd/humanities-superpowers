# Conflicting Evidence

This synthetic example prevents supportive source counting from hiding counterevidence.

Claim C1 says a bounded interface pattern always increases user agency. E1 and E2 support a narrower relation; E3 documents a counterexample under the same selection criteria. All sources are synthetic fixtures.

The evidence ledger records `SUPPORTS`, `QUALIFIES`, and `CONTRADICTS`. Friction F1 is `EVIDENCE_CONFLICT` with `HIGH` severity. The gate returns `CONDITIONAL PASS`, not because two entries outvote one, but because the researcher must choose whether to narrow C1, add discriminating evidence, or withdraw it. The conflict is not harmonized.
