# End-to-End Research Session Example

This example demonstrates orchestration, state recording, a failed gate, rollback, and resumption. It is intentionally compact and does not claim to be a completed article.

## Scenario

A researcher asks how platform interfaces mediate the experience of cultural memory. The first argument overgeneralizes from two interface cases. Stress testing returns `ROLLBACK` to scope definition. The revised scope is limited to two named interfaces and a defined period. Citation audit then leaves one historical claim unverified, so the submission gate returns `PAUSE`.

## Files

- [`session-01.json`](session-01.json): state and provenance record
- [`gate-history.md`](gate-history.md): visible gate sequence
- [`handoff-trace.md`](handoff-trace.md): skill-to-skill trace

The final status is not failure of the framework. It is a successful refusal to call unresolved work submission-ready.
