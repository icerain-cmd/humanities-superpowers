# Rival Interpretation

A synthetic passage repeats a phrase and then interrupts it with a syntactic break. Interpretation I1 reads repetition as continuity. Interpretation I2 reads the break as qualified discontinuity. Both identify observable features and both remain defensible.

The skill creates `RIVAL_INTERPRETATION`, preserves I1 and I2 as `PROPOSED`, and routes `RESEARCHER_DECISION_REQUIRED`. It does not call either reading a fact or select the more fluent account.
