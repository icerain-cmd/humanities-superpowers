# Fricturn 2.0

Humanities Superpowers 2.0 makes interpretive friction, traceable scholarly judgment, and epistemic return explicit research objects.

- Verification state asks whether material was checked; evidential standing asks what it does for a claim.
- Agent recommendations remain separate from researcher decisions.
- Rival readings and counterevidence are preserved.
- A historical gate result has a separate current validity.
- New knowledge may reopen an earlier object without deleting its history.

The project still contains 13 core skills and one router, uses only `PASS`, `CONDITIONAL PASS`, and `FAIL`, and treats memory as workflow context rather than evidence.
