# Methodology

Humanities Superpowers treats scholarly judgment—not prose generation—as the scarce resource.

Its method rests on five principles:

1. **Research before prose.**
2. **Unknown is better than fabricated.**
3. **Evidence outranks confidence.**
4. **Researcher responsibility remains visible.**
5. **Failure is a valid workflow outcome.**

The framework implements these principles through research objects, skill contracts, explicit epistemic states, quality gates, and rollback.

See the full [white paper](white-paper.md), [design principles](https://github.com/icerain-cmd/humanities-superpowers/blob/main/docs/DESIGN_PRINCIPLES.md), and [Research Specification](https://github.com/icerain-cmd/humanities-superpowers/tree/main/docs/specification).
