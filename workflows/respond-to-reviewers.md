# Workflow: respond to reviewers

1. Preserve the original reviews unchanged.
2. Run `responding-to-peer-review` to atomize and classify comments.
3. Use the relevant substantive skill for each major issue.
4. Make manuscript changes before drafting claims about those changes.
5. Run `auditing-citations` for all added or corrected sources.
6. Run `checking-terminology-consistency` after conceptual revisions.
7. Reconcile every response-letter location with the revised manuscript.
8. Run `verifying-before-submission` on manuscript, response letter, and venue requirements.
