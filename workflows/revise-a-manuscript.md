# Workflow: revise a humanities manuscript

1. Run `reviewing-manuscript` to create a neutral synopsis and prioritized diagnosis.
2. Use `scoping-argument-boundary` if the thesis is diffuse or overclaims.
3. Use `planning-humanities-argument` to rebuild section dependencies.
4. Use `performing-close-reading` where interpretation lacks textual or material support.
5. Use `structuring-humanities-argument` to reorganize researcher-provided material.
6. Run `stress-testing-argument` on the revised thesis.
7. Run `checking-terminology-consistency` and `auditing-citations`.
8. Run `verifying-before-submission`; do not declare completion on a FAIL.
